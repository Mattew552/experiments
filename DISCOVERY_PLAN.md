# Автоматическое обнаружение вентиляторов — план для Test

## Что уже возможно без аппаратных команд

LibreHardwareMonitor перечисляет датчики температуры, RPM и доступные элементы Control. В `Test` добавлена read-only выборка активных тахометров Super I/O в окне диагностики. Она не приписывает тахометрам физические роли и не разрешает запись. Нулевой RPM может означать пустой разъём, остановленный вентилятор или отсутствие тахосигнала; по одному чтению это не различить.

## Почему полного автоуправления пока нет

На проверенной плате библиотека называет входы `Fan #N`, а не `CPU_FAN1` или `SYS_FAN3`. Даже совпадение номера `fan/N` и `control/N` не доказывает соответствие конкретному разъёму или проводке. Разветвитель даёт один управляющий канал и обычно один тахосигнал для двух физических вентиляторов. Программе неизвестно, какие разъёмы заняты и какой вентилятор охлаждает CPU. Автоматически писать в неизвестный канал поэтому нельзя.

## Следующий безопасный этап

1. Пассивно определить модель платы, Super I/O, достоверную температуру CPU и список активных RPM. Показать безымянные графики для найденных тахометров, не называя их корпусными или CPU.
2. Предложить короткий мастер сопоставления. После проверки температуры, RPM CPU и отсутствия другой программы он изменяет только один разрешённый канал на ненулевое значение на несколько секунд. Тот же сторожевой процесс возвращает исходные регистры при штатном и аварийном завершении. Никаких команд GPU и автоматического 0%.
3. Сравнить RPM до/после с учётом задержки раскрутки; неоднозначные или отсутствующие изменения оставить неподтверждёнными. Пользователь подтверждает физическую группу по кабелю или наблюдению за крыльчаткой. Лишь затем становится доступна запись в обычном режиме.
4. Хранить результат только для этой установки Windows. При переносе настроек, смене платы или недоступном идентификаторе машины управление блокировать.
5. Отдельно проверять 0% только для подтверждённых корпусных каналов при работающем CPU-кулере. Задний Molex и подсветка не участвуют.

Модель платы может помочь предложить названия разъёмов, но не подтверждает фактическую проводку. Универсальное управление с нулём действий пользователя не будет безопасным для неизвестной сборки.
