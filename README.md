# FanGuardian

Приложение Windows 11 для управления проверенными каналами корпусных вентиляторов и CPU-кулера. Текущая версия аппаратно проверена на MSI B450 TOMAHAWK MAX с контроллером Nuvoton NCT6797D. На других ПК она может читать доступные датчики, но не отправляет команды без привязок, подтверждённых именно на этом компьютере.

## Запуск

Распакуйте архив целиком и запустите `FanGuardian.exe`. Готовая сборка включает .NET Runtime. Для чтения датчиков платы требуется работающий PawnIO и разрешение запроса UAC. Приложение не устанавливает драйвер.

Главный экран показывает три режима, температуру и RPM CPU, два графика передних групп, выбор ручного профиля и ссылку «Настроить кривые». Сохранённые кривые задаются точками `температура:процент`, например `30:40, 50:55, 70:80, 85:100`. Профили «Тихий», «Сбалансированный» и «Производительный» имеют разные исходные кривые.

- **BIOS / Автоматически:** приложение не задаёт скорость вентиляторов.
- **Передние выключены:** останавливаются только два подтверждённых передних канала; CPU-кулер остаётся под управлением платы. Задний вентилятор питается от Molex и программно недоступен.
- **Ручной режим:** CPU-кулер и две передние группы следуют выбранным кривым.

Значение CPU 0 °C считается ошибкой чтения. При недостоверной температуре, опасном нагреве или потере RPM CPU управление сбрасывается. Приложение никогда не отправляет команды вентиляторам GPU. Отдельный процесс хранит исходное состояние регистров вентилятора и восстанавливает его при завершении или потере связи с окном. Проверены обычные переходы режимов и принудительное завершение окна; отказ самого сторожа и сон/пробуждение остаются непроверенными.

Настройки и журналы хранятся в `%LOCALAPPDATA%\FanGuardian` вне репозитория. Привязки закреплены за установкой Windows и не переносятся на другой ПК. Если идентификатор машины недоступен или не совпадает, управление отключается. На другой плате графики проверенных групп скрываются.

## Диагностика и сборка

`FanGuardian.exe --probe` выводит датчики без аппаратной записи. `FanGuardian.exe --self-test` запускает проверки логики на подставных данных. Для сборки из исходников требуется .NET 9 SDK:

```powershell
dotnet restore FanGuardian/FanGuardian.csproj
dotnet build FanGuardian/FanGuardian.csproj -c Release
```

Библиотека [LibreHardwareMonitorLib 0.9.6](https://www.nuget.org/packages/LibreHardwareMonitorLib/0.9.6) распространяется по MPL-2.0. [PawnIO](https://github.com/namazso/PawnIO) устанавливается отдельно и имеет собственную лицензию. Разъёмы подсветки 5V ARGB не входят в приложение; напрямую соединять их с 12V JRGB платы нельзя.
