# FanGuardian

Приложение для Windows с автоматическим чтением доступных датчиков вентиляторов. Управление аппаратно проверено только на MSI B450 TOMAHAWK MAX с контроллером Nuvoton NCT6797D. На других ПК программа показывает найденные тахометры и температуру CPU, когда библиотека может их прочитать, но не отправляет команды без привязок, подтверждённых именно на этом компьютере.

## Запуск

Распакуйте архив целиком и запустите `FanGuardian.exe`. Для этой сборки нужен установленный .NET 9 Desktop Runtime. Для чтения датчиков платы требуется работающий PawnIO и разрешение запроса UAC. Приложение не устанавливает драйвер.

Главный экран показывает три режима, температуру CPU, графики обнаруженных тахометров, выбор ручного профиля и ссылку «Настроить кривые». На данном проверенном ПК графики подписаны физическими группами; на других ПК они подписаны только именами датчиков. RPM CPU отдельно выводится после подтверждения соответствующего датчика. Сохранённые кривые задаются точками `температура:процент`, например `30:40, 50:55, 70:80, 85:100`. Профили «Тихий», «Сбалансированный» и «Производительный» имеют разные исходные кривые.

В ветке `Test` кнопка «Подключить новую систему» последовательно проверяет доступные каналы платы: кратко задаёт 100%, сравнивает RPM и возвращает исходный режим. Сторож прекращает пробу через шесть секунд даже при потере ответа интерфейса. Рост RPM даёт только вероятную пару канала и тахометра; отсутствие роста **не** означает пустой разъём. Каналы с уже выставленными 95–100% пропускаются. Результат пока не включает управление на новом ПК: физическую роль вентилятора нужно подтвердить отдельно. Этот мастер ещё не проверен на другом оборудовании.

- **BIOS / Автоматически:** приложение не задаёт скорость вентиляторов.
- **Передние выключены:** останавливаются только два подтверждённых передних канала; CPU-кулер остаётся под управлением платы. Задний вентилятор питается от Molex и программно недоступен.
- **Ручной режим:** CPU-кулер и две передние группы следуют выбранным кривым.

Температура выбирается из датчиков самого процессора AMD или Intel: Tctl/Tdie, Tctl или CPU Package. Значение 0 °C и датчики материнской платы с похожим названием не используются как температура CPU. При недостоверной температуре, опасном нагреве или потере RPM CPU управление сбрасывается. Приложение никогда не отправляет команды вентиляторам GPU. Отдельный процесс хранит исходное состояние регистров вентилятора и восстанавливает его при завершении или потере связи с окном. Проверены обычные переходы режимов и принудительное завершение окна на указанном ПК; отказ самого сторожа и сон/пробуждение остаются непроверенными.

Настройки и журналы хранятся в `%LOCALAPPDATA%\FanGuardian` вне репозитория. Привязки закреплены за установкой Windows и не переносятся на другой ПК. Если идентификатор машины недоступен или не совпадает, управление отключается. Датчики могут появиться на экране без возможности управления: число и имена RPM не раскрывают физическое подключение. Поддержка чтения зависит от платы, контроллера и доступа к драйверу; запуск на другом ПК пока аппаратно не проверен.

## Диагностика и сборка

`FanGuardian.exe --probe` выводит датчики без аппаратной записи. `FanGuardian.exe --self-test` запускает проверки логики на подставных данных. Для сборки из исходников требуется .NET 9 SDK:

```powershell
dotnet restore FanGuardian/FanGuardian.csproj
dotnet build FanGuardian/FanGuardian.csproj -c Release
```

Библиотека [LibreHardwareMonitorLib 0.9.6](https://www.nuget.org/packages/LibreHardwareMonitorLib/0.9.6) распространяется по MPL-2.0. [PawnIO](https://github.com/namazso/PawnIO) устанавливается отдельно и имеет собственную лицензию. Разъёмы подсветки 5V ARGB не входят в приложение; напрямую соединять их с 12V JRGB платы нельзя.
